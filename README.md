# Noesis Project

This directory contains the various components of the Noesis project.

## Sub-projects

- **Noesis Core (`core/`)**: The main synthetic consciousness simulation engine.
  - [Read more in `core/README.md`](core/README.md)
- **Noesis Gateway (`gateway/`)**: A platform connector hub for integrating with the Noesis system.
  - [Read more in `gateway/README.md`](gateway/README.md)
- **Noe Language (`noe-lang/`)**: Reference implementation and specification for the Noesis Object Encoding (.noe) format.
  - [Read more in `noe-lang/README.md`](noe-lang/README.md)
- **Noe UI (`noe-ui/`)**: Web interface featuring the synthetic conscious pixel.
  - [Read more in `noe-ui/README.md`](noe-ui/README.md)

For detailed information on each sub-project, please refer to their respective `README.md` files.
